# D&D Initiative Tracker

A fully-featured web application for tracking initiative in Dungeons & Dragons and other tabletop RPG combat encounters.

## Overview

This initiative tracker was designed to streamline combat management for Dungeon Masters and players alike. Built over a two-week development period, it provides all the essential features needed for efficient initiative tracking and encounter management.

## Features

- **Initiative Management** - Add, edit, and remove combatants with ease
- **Turn Tracking** - Clear visual indicators for whose turn it is
- **Automatic Sorting** - Initiative order automatically updates based on rolls
- **Persistent Data** - Save and load encounters for future sessions
- **User-Friendly Interface** - Intuitive design optimized for quick access during gameplay

## Use Cases

Perfect for:
- D&D 5th Edition campaigns
- Pathfinder sessions
- Any d20-based tabletop RPG
- Virtual or in-person game sessions

## Getting Started

Simply visit the live website and start adding your combatants. No installation or account required.
